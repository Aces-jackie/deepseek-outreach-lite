# DeepSeek 外贸建联两件套

给使用 **DeepSeek 网页版** 的外贸同学准备的一套轻量工作流：不需要安装任何专业软件，开 2 个对话、粘贴 2 段提示词就能跑起来。

| 对话框（改名用） | 技能文件 | 干什么 |
|---|---|---|
| 「建联文案」 | `skills/1-建联文案生成.md` | 自带知识库：首次上传资料建库 → 之后出客户站筛选简报 + 生成建联文案 |
| 「回复指导」 | `skills/2-回复指导器.md` | 自带知识库：首次上传资料建库 → 之后客户来消息（贴文字/截图）→ 研判局势 + 给回复方向 |

两个对话**开头都内置了知识库功能**：第一次把资料（Excel/Word/PDF/图片）传进去，它就蒸馏成一份知识库存在对话里，之后所有输出只依据这份知识库，不瞎编。

另有可选进阶工具（见下文「进阶」），嫌手动麻烦再用。

## 一、下载（二选一）

**方式 A：直接下 ZIP（推荐，不用装任何东西）**
1. 打开本仓库页面 → 点绿色 **Code** 按钮 → **Download ZIP**
2. 解压到桌面即可，比如 `D:\deepseek-outreach-lite\`

**方式 B：git 拉取（会 git 的再用）**
```
git clone https://github.com/Aces-jackie/deepseek-outreach-lite.git
```

## 二、开箱三步（5 分钟）

**第 1 步**：打开 [DeepSeek 网页版](https://chat.deepseek.com)，新建 2 个对话，分别改名为：**建联文案**、**回复指导**（左键点对话名可改名）。

**第 2 步**：把两个技能文件用记事本打开（在 `skills/` 文件夹里），**整段复制粘贴**到对应的对话里发送：
- 「建联文案」对话 ← 粘 `1-建联文案生成.md` 的内容
- 「回复指导」对话 ← 粘 `2-回复指导器.md` 的内容

> 提示词在各自对话里长期有效。以后每次直接打开同名对话干活就行，**不用重新粘贴**。

**第 3 步**：把 `templates/客户跟进表-简化模板.xlsx` 复制一份出来，这就是你的客户台账。

## 三、日常怎么用

### 第一次用：给两个对话都「喂」资料
1. 把你的产品资料、报价单、FAQ、客户聊天记录、产品图……**整理到一个文件夹**
2. 打开「建联文案」对话，把资料全部上传 → 它输出一份八段格式的《知识库文档》，这份知识库从此留在对话里
3. 打开「回复指导」对话，**把同一批资料再传一遍** → 同样生成它自己的知识库
4. 以后有新资料，**记得两个对话都传一份**（它们的知识库是各管各的），传完它会自动更新

> **知识库是全套的核心**：资料越全，文案和回复指导越靠谱。感觉它答得虚，多半是知识库缺料——补资料就行。

### 开发新客户站（建联文案对话）
1. 打开「建联文案」对话
2. 按它的提示，自己打开客户网站，把店名/slogan/几个产品价格/发货政策/About 介绍抄给它
3. 它给你：筛选简报（值不值得建联）+ 建联文案（英文成稿+中文对照）
4. 把结论和文案填进 Excel 模板对应列；产品主图在浏览器右键另存，Excel 里「插入 → 图片」放到主图列

### 客户来消息了（回复指导对话）
1. 打开「回复指导」对话
2. 把客户的聊天记录**直接粘贴文字**，或**上传聊天截图**（WhatsApp/Telegram/IG/邮件截图都能读）
3. 它固定给你五段：客户在哪个阶段 → 关键信号 → 卡点 → 建议回复 → 本轮禁区
4. 要直接能发的英文消息，就回一句「给成稿」

## 四、Excel 模板列说明

| 列 | 填什么 |
|---|---|
| 店铺链接 / 店名 | 客户网站 |
| 主营品类 / 价格区间 | 从简报抄 |
| 简报结论 | 值不值得建联 + 一句话理由 |
| 建联文案 | DeepSeek 生成的文案（发送前自己过一遍） |
| 主图 | 手动「插入 → 图片」，建议列宽调小当缩略图看 |
| 状态 | 候选 / 已简报 / 已发文案 / 已回复 / 报价中 / 成交 / 放弃 |
| 备注/日期 | 最新进展 + 日期 |

想加列、改列直接自己改，或者问 DeepSeek「帮我把这个表加一列XX」。

## 五、进阶（可选）：一键抓店铺工具

手动抄店铺信息嫌麻烦？`tools/` 里有个本地小脚本，双击运行、粘贴链接，自动抓：在售产品数、价格区间、品类标签、在售样例、物流时效信号，**并自动下载主图**。

**一次性安装（只需做一次）：**
1. 装 Node.js：打开 https://nodejs.org → 下载 **LTS 版** → 一路下一步
2. 完事

**以后每次用：**
1. 双击 `tools/双击运行-抓店铺.bat`
2. 粘贴店铺链接，回车
3. 结果在 `site-data/店铺域名/` 里：
   - `summary.txt` → 整段复制进「建联文案」对话
   - `main-image.xxx` → 主图，手动插入 Excel

> 脚本只在你自己电脑上跑、只访问你给的那个网站，不经过任何第三方。个别网站有反爬防护时脚本会提示你走手动模式。

## 六、常见问题

**Q：为什么提示词每次新对话要重贴？**
DeepSeek 的对话之间互不相通。同一个对话里粘过就一直有效；只有开新对话才需要重贴。

**Q：为什么两个对话都要传资料？**
DeepSeek 对话之间互相看不到。每个对话各建各的知识库，资料更新时两边都补一份就好。

**Q：资料太多，知识库会不会记不全？**
知识库被要求控制在 3000 字内、只抓重点。如果它提示超了，让它「精简到 3000 字以内」即可。

**Q：它编造了我们没有的参数/价格怎么办？**
提示词里已明令禁止并要求标注来源。发现一次，当场回它「知识库里没有这条，删除并标注空缺」，它会记住约束。

**Q：知识库要重传吗？**
不用。知识库建好后一直留在本对话里，只有开全新对话才需要重传资料重新建库。
