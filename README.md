# DeepSeek 外贸建联三件套

给使用 **DeepSeek 网页版** 的外贸同学准备的一套轻量工作流：不需要安装任何专业软件，开 3 个对话、粘贴 3 段提示词就能跑起来。

整套东西只有三件事：

| 对话框（改名用） | 技能文件 | 干什么 |
|---|---|---|
| 「知识库」 | `skills/1-知识库管理员.md` | 把你的资料（Excel/Word/PDF/图片）蒸馏成一份标准《知识库文档》 |
| 「建联文案」 | `skills/2-建联文案生成.md` | 出客户站筛选简报 + 生成建联文案，只依据知识库，不瞎编 |
| 「回复指导」 | `skills/3-回复指导器.md` | 客户来消息（贴文字或截图）→ 研判局势 + 给回复方向 |

另有可选进阶工具（见下文「进阶」），嫌手动麻烦再用。

## 一、下载（二选一）

**方式 A：直接下 ZIP（推荐，不用装任何东西）**
1. 打开本仓库页面 → 点绿色 **Code** 按钮 → **Download ZIP**
2. 解压到桌面即可，比如 `D:\deepseek-outreach-lite\`

**方式 B：git 拉取（会 git 的再用）**
```
git clone https://github.com/Aces-jackie/deepseek-outreach-lite.git
```

## 二、开箱三步（5 分钟）

**第 1 步**：打开 [DeepSeek 网页版](https://chat.deepseek.com)，新建 3 个对话，分别改名为：**知识库**、**建联文案**、**回复指导**（左键点对话名可改名）。

**第 2 步**：把三个技能文件用记事本打开（在 `skills/` 文件夹里），**整段复制粘贴**到对应的对话里发送：
- 「知识库」对话 ← 粘 `1-知识库管理员.md` 的内容
- 「建联文案」对话 ← 粘 `2-建联文案生成.md` 的内容
- 「回复指导」对话 ← 粘 `3-回复指导器.md` 的内容

> 提示词在各自对话里长期有效。以后每次直接打开同名对话干活就行，**不用重新粘贴**。

**第 3 步**：把 `templates/客户跟进表-简化模板.xlsx` 复制一份出来，这就是你的客户台账。

## 三、日常怎么用

### 第一次用：先把知识库建起来
1. 打开「知识库」对话，把你的产品资料、报价单、FAQ、客户聊天记录、产品图……**全部上传**（能传的都传）
2. 它会输出一份标准八段格式的《知识库文档》
3. **把这份文档复制，存成 `KB.txt` 放到桌面**——这是后面两个对话的「粮食」
4. 以后有新资料就回这个对话上传，它会重新输出完整版，你再覆盖保存 KB.txt

### 开发新客户站（建联文案）
1. 打开「建联文案」对话，上传最新的 `KB.txt`
2. 按它的提示，自己打开客户网站，把店名/slogan/几个产品价格/发货政策/About 介绍抄给它
3. 它给你：筛选简报（值不值得建联）+ 建联文案（英文成稿+中文对照）
4. 把结论和文案填进 Excel 模板对应列；产品主图在浏览器右键另存，Excel 里「插入 → 图片」放到主图列

### 客户来消息了（回复指导）
1. 打开「回复指导」对话，上传最新的 `KB.txt`
2. 把客户的聊天记录**直接粘贴文字**，或**上传聊天截图**（WhatsApp/Telegram/IG/邮件截图都能读）
3. 它固定给你五段：客户在哪个阶段 → 关键信号 → 卡点 → 建议回复 → 本轮禁区
4. 要直接能发的英文消息，就回一句「给成稿」

> **知识库是全套的核心**：KB.txt 越全，文案和回复指导越靠谱。感觉它答得虚，多半是知识库缺料——回「知识库」对话补资料。

## 四、Excel 模板列说明

| 列 | 填什么 |
|---|---|
| 店铺链接 / 店名 | 客户网站 |
| 主营品类 / 价格区间 | 从简报抄 |
| 简报结论 | 值不值得建联 + 一句话理由 |
| 建联文案 | DeepSeek 生成的文案（发送前自己过一遍） |
| 主图 | 手动「插入 → 图片」，建议列宽调小当缩略图看 |
| 状态 | 候选 / 已简报 / 已发文案 / 已回复 / 报价中 / 成交 / 放弃 |
| 备注/日期 | 最新进展 + 日期 |

想加列、改列直接自己改，或者问 DeepSeek「帮我把这个表加一列XX」。

## 五、进阶（可选）：一键抓店铺工具

手动抄店铺信息嫌麻烦？`tools/` 里有个本地小脚本，双击运行、粘贴链接，自动抓：在售产品数、价格区间、品类标签、在售样例、物流时效信号，**并自动下载主图**。

**一次性安装（只需做一次）：**
1. 装 Node.js：打开 https://nodejs.org → 下载 **LTS 版** → 一路下一步
2. 完事

**以后每次用：**
1. 双击 `tools/双击运行-抓店铺.bat`
2. 粘贴店铺链接，回车
3. 结果在 `site-data/店铺域名/` 里：
   - `summary.txt` → 整段复制进「建联文案」对话
   - `main-image.xxx` → 主图，手动插入 Excel

> 脚本只在你自己电脑上跑、只访问你给的那个网站，不经过任何第三方。个别网站有反爬防护时脚本会提示你走手动模式。

## 六、常见问题

**Q：为什么提示词每次新对话要重贴？**
DeepSeek 的对话之间互不相通。同一个对话里粘过就一直有效；只有开新对话才需要重贴。

**Q：知识库文档太长怎么办？**
知识库管理员被要求控制在 3000 字内。如果它提示超了，让它「精简到 3000 字以内」即可。

**Q：它编造了我们没有的参数/价格怎么办？**
提示词里已明令禁止并要求标注来源。发现一次，当场回它「知识库里没有这条，删除并标注空缺」，它会记住约束。

**Q：三个对话能合并成一个吗？**
不建议。分开三个对话各自职责单一，回答质量更稳，也更不容易串。
